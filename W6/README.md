# 🌟 แฟ้มสะสมผลงานส่วนตัว (Personal Portfolio Website)

เว็บไซต์ Portfolio ส่วนตัวสไตล์โมเดิร์น สวยงามระดับพรีเมียม (Glassmorphism + Neon Glow) รองรับการแสดงผลทั้งบนมือถือ แท็บเล็ต และคอมพิวเตอร์อย่างสมบูรณ์แบบ พร้อมระบบจัดการแก้ไขข้อมูลและเปลี่ยนรูปภาพในตัว (In-browser CMS & Live Photo Upload) บันทึกข้อมูลลงในเครื่องโดยอัตโนมัติ

---

## ✨ ฟีเจอร์เด่นของเว็บไซต์ (Key Features)

1. **📸 แก้ไขและเปลี่ยนรูปโปรไฟล์ได้ทันที (Profile Photo Upload):**
   - คลิกที่รูปโปรไฟล์ในหน้าแรก เพื่ออัปโหลดรูปภาพใหม่จากเครื่องคอมพิวเตอร์ของคุณ (รองรับ JPG, PNG, WebP) หรือใส่ URL รูปภาพ
   - มีระบบพรีวิวรูปภาพแบบสด และบันทึกลงในเครื่อง (LocalStorage) ทันที ไม่สูญหายเมื่อรีเฟรชหน้าเว็บ
   - มีปุ่มคืนค่าเป็นรูปตัวอย่างเริ่มต้นได้ตลอดเวลา

2. **👤 หน้าแนะนำตัว (About Me):**
   - ข้อความแนะนำตัวและเป้าหมายการทำงาน
   - ตารางข้อมูลส่วนบุคคล (วันเกิด, ที่อยู่, ภาษาที่สื่อสาร, วุฒิการศึกษา, สถานะการทำงาน)
   - การ์ดจุดเด่นและความเชี่ยวชาญหลัก (Core Highlights)

3. **🎓 ประวัติการศึกษา (Education Timeline):**
   - แสดงประวัติการศึกษาในรูปแบบเส้นเวลา (Glowing Interactive Timeline)
   - ระบุวุฒิการศึกษา, สถาบัน, ปีที่ศึกษา, เกรดเฉลี่ย (GPA/Honors) และกิจกรรมเด่น
   - สามารถกดเพิ่ม/แก้ไข/ลบ รายการประวัติการศึกษาได้เอง

4. **⚡ ทักษะส่วนตัว (Skills & Capabilities):**
   - **ทักษะทางเทคนิค (Technical Skills):** แถบวัดระดับความเชี่ยวชาญแบบเปอร์เซ็นต์ (0-100%) พร้อมแอนิเมชัน
   - **เครื่องมือที่ใช้งาน (Tools & Tech):** ป้าย Tag Badge สไตล์โมเดิร์น (เช่น Figma, Git, Docker, VS Code)
   - **ทักษะการทำงานร่วมกับผู้อื่น (Soft Skills):** การ์ดแสดงความสามารถด้านการสื่อสารและการแก้ปัญหา

5. **💼 ผลงานที่เคยทำ (Featured Projects Showcase):**
   - แสดงผลงานในรูปแบบการ์ด พร้อมแท็กเทคโนโลยีที่ใช้
   - ตัวกรองแยกตามหมวดหมู่: ทั้งหมด (All), Web Application, Mobile App, UI/UX Design
   - ปุ่ม **"ดูรายละเอียด"** เพื่อเปิดหน้าต่างป็อปอัป (Modal) แสดงรายละเอียดเชิงลึก
   - ปุ่มเปิดดูเว็บไซต์จริง (Live Demo) และซอร์สโค้ด (GitHub)
   - สามารถเพิ่มผลงานใหม่ หรือแก้ไขผลงานเดิมผ่านแผงควบคุมได้

6. **📬 เส้นทางติดต่อ (Get In Touch):**
   - ช่องทางติดต่อโดยตรง: อีเมล (คลิกส่งได้ทันที), เบอร์โทรศัพท์, ที่อยู่
   - ปุ่มเปิด **Line QR Code** สำหรับสแกนเพิ่มเพื่อนใน Line ได้ทันที
   - ลิงก์เชื่อมต่อไปยัง Social Media (GitHub, LinkedIn, Facebook, Instagram)
   - แบบฟอร์มส่งข้อความ (Interactive Contact Form)

7. **🛠️ โหมดแก้ไขข้อมูลในตัว (Built-in CMS & Live Editor):**
   - ปุ่ม **"จัดการข้อมูล Portfolio"** สีสันสะดุดตาที่มุมขวาล่าง
   - สามารถแก้ไขข้อมูลทุกส่วนได้โดยไม่ต้องแตะโค้ด
   - **ระบบสำรองข้อมูล (JSON Backup & Restore):** ส่งออกเป็นไฟล์ `.json` เพื่อเก็บสำรองไว้ หรือนำไปเปิดบนเครื่องอื่นได้

8. **🌓 สลับโหมดมืด / โหมดสว่าง (Dark / Light Theme):**
   - สลับธีมได้ด้วยคลิกเดียว และจดจำการตั้งค่าของผู้ใช้งาน

9. **📄 รองรับการพิมพ์เป็นเอกสาร CV / Resume (Print to PDF):**
   - กดปุ่ม **"พิมพ์ CV"** ที่แถบเมนู เพื่อพิมพ์หรือบันทึกเป็นไฟล์ PDF ทันที

## 🚀 วิธีเปิดใช้งานบนเครื่องของคุณ (Local Usage)

### วิธีที่ 1: เปิดผ่านเบราว์เซอร์โดยตรง (ง่ายที่สุด)
ดับเบิลคลิกที่ไฟล์ `index.html` หรือคลิกขวาแล้วเลือก **Open with Google Chrome** (หรือ Edge, Brave, Safari) เว็บไซต์จะเปิดขึ้นมาใช้งานได้ทันที 100%!

### วิธีที่ 2: เปิดผ่าน Local Server
ปัจจุบันระบบได้เปิดเซิร์ฟเวอร์จำลองไว้แล้วที่:
👉 **http://localhost:3000**

## 🌐 วิธีนำขึ้นออนไลน์สาธารณะ (เปิดให้คนอื่นเข้าชมได้ตลอด 24 ชม. ฟรี!)

คุณสามารถนำเว็บไซต์นี้ขึ้นสู่อินเทอร์เน็ตสาธารณะได้ฟรี ไม่มีค่าใช้จ่ายตลอดชีพ ด้วยวิธีใดวิธีหนึ่งดังนี้:

### วิธีที่ 1: อัปโหลดผ่าน Vercel หรือ Netlify (แนะนำ ง่ายที่สุด ภายใน 1 นาที)
1. ไปที่เว็บไซต์ [Vercel.com](https://vercel.com) หรือ [Netlify.com](https://www.netlify.com) แล้วสมัครสมาชิกฟรี
2. ที่หน้า Dashboard เลือก **"Add New Project"** หรือลากโฟลเดอร์ `W6` ทั้งโฟลเดอร์ไปวางที่หน้าเว็บ Netlify Drop
3. ภายในไม่กี่วินาที คุณจะได้ลิงก์สาธารณะ เช่น `https://your-name-portfolio.vercel.app` ซึ่งสามารถส่งให้ผู้อื่น หรือใส่ในเรซูเมเพื่อเข้าชมได้ตลอด 24 ชั่วโมง!

### วิธีที่ 2: นำขึ้น GitHub Pages
1. นำโค้ดขึ้น GitHub Repository (สร้างเป็น Public Repo)
2. เข้าไปที่เมนู **Settings** > **Pages**
3. ที่หัวข้อ **Branch** เลือกเป็น `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. คุณจะได้ URL สาธารณะ เช่น `https://username.github.io/portfolio/` ฟรีตลอด 24 ชั่วโมง

```text
W6/
├── index.html        # โครงสร้างหน้าเว็บหลัก (HTML5 Semantic)
├── 258.html          # ไฟล์สำเนาหน้าเว็บสำหรับใช้งาน
├── css/
│   └── style.css     # ดีไซน์ระบบ Glassmorphism, ธีมสี, แอนิเมชัน และ Print Stylesheet
├── js/
│   ├── data.js       # ข้อมูลตั้งต้นของ Portfolio (แก้ไขได้ผ่านหน้าเว็บ)
│   └── app.js        # ตัวจัดการสถานะ, การอัปโหลดรูป, การบันทึก LocalStorage และระบบควบคุม
└── README.md         # เอกสารคู่มือการใช้งานและวิธีเผยแพร่ออนไลน์
```
